**★ SSH сужен до адресов владельца (09.09.2026).** Повод: порт 22 был открыт всему интернету, ~157 попыток подбора в час, fail2ban забанил 199 адресов. **Важно понимать масштаб выигрыша:** пароли выключены (`PasswordAuthentication no`, `PermitRootLogin without-password`), подобрать там нечего — сужение даёт не защиту от подбора, а страховку от будущей дыры в самом sshd (прецедент regreSSHion 2024) и чистые логи.

Что показал разбор входов за 40 дней: **все успешные входы — одним ключом `andrey@exlogist` (SHA256:vMWypC/…)** с четырёх адресов владельца: `109.207.173.63` (1057 входов), `92.62.63.76` (8), `178.34.43.202` (2), `92.255.102.90` (1). **Ключевой факт: 99% доступа идёт через 109.207.173.63 — это СТАРЫЙ сервер Serverspace, который работает VPN-выходом машины владельца.** То есть и мои команды приходят с него. Владелец подтвердил: оплачен до конца года, держим. К концу года это станет точкой отказа — заранее перевести доступ на WireGuard.

Сделано: `ufw allow from 109.207.173.63 to any port 22 proto tcp`, то же для `92.62.63.76`, затем `ufw --force delete allow 22/tcp`. **Обязательно проверять IPv6: у сервера есть публичный `2a02:6b40:2000:1518::1/48`**, и если убрать только v4-правило, перебор просто переедет на v6 (ufw при удалении `allow 22/tcp` снимает обе версии — но результат проверять по `ufw status numbered`). Попутно убрано осиротевшее `iptables -A INPUT -p udp --dport 61022 -j ACCEPT` (добавлено вручную, в конфигах его нет, при ребуте не вернулось бы).

**Приём для правки файрвола вслепую:** перед изменением вооружать автооткат `systemd-run --on-active=10min --unit=ufw-ssh-rollback /usr/sbin/ufw allow 22/tcp` — если ошибёшься в правиле, доступ вернётся сам через 10 минут; снимать таймер только после того, как НОВОЕ соединение прошло. Порядок операций: сначала добавить разрешения своим адресам, потом удалять общее правило (иначе будет окно без доступа). Аварийный путь на крайний случай — веб-консоль Fornex, пароль root цел.

⚠️ **Грабля замера:** сразу после правки окно `journalctl --since "6 minutes ago"` захватило время ДО изменения и показало «4 попытки дошли до sshd» — выглядело как незакрытая дыра.

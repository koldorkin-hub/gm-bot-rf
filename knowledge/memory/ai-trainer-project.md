Проект «ИИ-Тренер» — приватный self-hosted Telegram-бот персонального фитнес-коучинга на n8n. Сейчас работает один бот @GymAK_AI_Bot (клиент `gymak`, он же владелец); цель — тиражировать его как персональных ботов другим клиентам, каждому свой бот со своей историей.

Ценности: приватность (всё self-hosted, никаких внешних SaaS для хранения данных), только production-ready решения без промежуточных заглушек, модульная архитектура (отдельные боты по ролям, а не один комбайн).

**Рамка:** система на фокус-группу до ~100 человек, не масштаб на тысячи. Не переусложнять под нагрузку, которой пока нет.

Роадмап (зафиксирован 18.07.2026, статусы на 21.07.2026):
1. ✅ Починить прод после переезда — [[n8n-postgres-memory-outage]]
2. ✅ Мультиарендность — [[n8n-multitenancy]]
3. ✅ Отказоустойчивость — [[n8n-resilience]]
4. ⬜ Распознавание фото (прогресс тела, скриншоты) — Claude Vision / base64. **Следующий по бэклогу.**
5. ⬜ Распознавание документов и PDF (анализы, отчёты)
6. ⬜ Уведомления и напоминания
7. ⬜ Трекинг тренировок/питания/воды, еженедельные отчёты
8. ⬜ Slash-команды (/start, /help, /stats)

Сверх роадмапа сделано: замена поиска на встроенный `web_search` Claude ([[n8n-websearch-tool]]), режим `/research` с PDF-отчётами ([[n8n-research-mode]]), бэкапы с проверенным восстановлением ([[backup-system]]).

Инфраструктура — [[ai-trainer-infra]]. Устройство бота — [[n8n-bot-workflow]]. Стиль работы владельца — [[owner-work-style]]. Текущая точка и незакрытые хвосты — файл `СОСТОЯНИЕ-ПРОЕКТА.md` в рабочем каталоге проекта.

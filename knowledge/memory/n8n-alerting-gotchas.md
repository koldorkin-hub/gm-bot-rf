Собрано 20.07.2026 при внедрении [[n8n-resilience]]. Общая черта: ошибка не видна в момент настройки и всплывает ровно тогда, когда тревога нужна.

**1. Error Workflow обязан быть АКТИВНЫМ.** Неактивный он молча не вызывается — в логе одна строка `Workflow "X" is not active and cannot be executed`, которую никто не читает. Прописать его в `settings.errorWorkflow` мало. Поймано настоящим боевым сбоем на одноразовом workflow; без этой проверки вся система уведомлений выглядела бы настроенной и была бы мертва.

**2. У узла Telegram нет режима «без разметки».** Только Markdown, MarkdownV2 и HTML, по умолчанию HTML. Текст ошибки произвольный, и на `&` (например, из URL запуска с параметрами) Telegram отвечает `400 can't parse entities` — тревога теряется целиком. Лечится узлом-подготовкой, который экранирует `&`, `<`, `>` перед отправкой.

**3. n8n обрезает сообщение брошенной ошибки по последнему «: ».** `throw new Error('Postgres недоступен: ... Бот: gymak')` доходит до владельца как `Ошибка: gymak`. Внутри текста тревоги двоеточий с пробелом быть не должно — использовать тире или запятую.

**Алерт о падении голоса (добавлен 01.08.2026).** Ошибки голосовой ветки шли только клиенту («Голос не распознан»), владелец не знал, что голос упал (напр. Groq 401 — сбитый ключ `GroqHdrAuth00001`). Теперь: ошибка `HTTP Request2/3` (out[1]) → `Голос: разбор сбоя` (Code, тянет HTTP-код из `error.message`/`error.stack`: `/^\s*(\d{3})/` либо `status code (\d{3})`) → веером в «Голос не распознан» (юзеру, как было) И в `Голос: системный?` (401/403/429/5xx — ключ/квота/сервис; битое аудио 400 НЕ алертит) → `Голос: анти-спам` → `Голос: алерт владельцу`. **Анти-спам без staticData** (его стирает деплой): таблица `ops_alert(kind PK, last_at)`, атомарный `INSERT ... ON CONFLICT DO UPDATE ... WHERE last_at < now()-interval '30 min' RETURNING kind` — вернул строку = можно слать (и last_at обновлён), 0 строк = подавлено (нода алерта не исполняется, нет входных items). Алерт шлёт тот же бот-тревог, что и Error Workflow (Telegram cred `372DoMw3VRfbXpFL`, chat владельца 255171226). Исходник `schema/transform-main-voice-alert.js`.

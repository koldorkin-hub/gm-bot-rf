Бот мультиязычный (02.08.2026). На старте спрашивает язык НА АНГЛИЙСКОМ (единственный первый вопрос), дальше ведёт всё — приветствие, онбординг, диалог — на выбранном языке. Смена: команда `/language` (переспросит) или словами. Claude нативно мультиязычный, так что суть — надёжно поймать и хранить выбор.

**Хранение:** колонка `client_profile.language` (текст; название языка по-английски: «Russian», «English», «Spanish»…). Сентинел `'__ASKING__'` = «вопрос задан, жду ответа». Существующие профили при внедрении бэкфилл на `'Russian'` (бот был русский), новые — NULL → спрашиваются. `save_profile` тоже умеет писать `language` (добавлен в WL и в SQL апсерта ProfileTool00001 — колонка/SELECT/DO UPDATE).

**★ КЛЮЧЕВОЙ УРОК: и ВОПРОС, и СОХРАНЕНИЕ языка — ДЕТЕРМИНИРОВАННЫЕ, НЕ через агента.**
- Первая попытка (LLM-директива в контексте: «если язык не выбран — спроси на английском») **провалилась**: у существующего юзера длинная история на русском ПЕРЕБИЛА директиву — агент просто здоровался по-русски вместо вопроса. Директива, зарытая в конце 13.7КБ промпта, не выигрывает у истории/персоны.
- Вторая проблема: даже когда агента просили сохранить выбор через `save_profile(language)` — он вызывал НЕ всегда → застревало в `'__ASKING__'`. **Полагаться на LLM для персиста критичного состояния нельзя.**

**Итоговая детерминированная схема (главный workflow, ДО агента, после `Пущен?`):**
`Пущен?[0] → Язык: чек`(SELECT language) `→ Язык: маршрут`(IF: lang=='' ИЛИ text=='/language' → спросить):
- **спросить:** `Язык: пометить`(UPSERT language='__ASKING__') → `Язык: вопрос`(sendMessage английский вопрос) → СТОП (агент не запускается).
- **не спросить → `Язык: отвечает?`**(IF lang=='__ASKING__'):
  - **да (пользователь ответил):** `Язык: запрос`(Code payload) → `Язык: определить`(HTTP Anthropic `claude-haiku-4-5`, system «выведи ТОЛЬКО название языка по-английски или UNCLEAR») → `Язык: разобрать`(Code: чистит, unclear?) → `Язык: ясно?`(IF): ясно → `Язык: сохранить`(UPDATE language=X) → `Пачка: занят?`(дальше обычный поток; `Load Profile` уже видит новый язык → агент приветствует на нём); невнятно → `Язык: вопрос`(переспрос, стоп).
  - **нет (язык уже выбран):** → `Пачка: занят?` (обычный поток).

**Директива в systemMessage (`Build Profile Context`, 3 состояния):** `'__ASKING__'` → «пользователь ответил, определи+save_profile+приветствуй» (фолбэк, в happy-path не срабатывает — язык уже сохранён детерминированно до Load Profile); реальный язык → «отвечай ВСЕГДА на нём, смена словами»; пусто → «спроси на английском» (фолбэк).

**Проверено живьём (02.08.2026):** `ку`→англ. вопрос(стоп); `русский`→определил Russian+сохранил; `/language`→переспрос→`english`→English; ещё `/language`→`русский`→обратно; в БД язык персистит, не застревает. Стоимость определения — haiku, копейки. Исходники `schema/transform-main-language-gate.js`, `-detect.js`, `-language-directive.js` (директива), `transform-profiletool-language.js` (save_profile).

**★ ЛОКАЛИЗАЦИЯ ВСЕГО КОНТЕНТА ДОВЕДЕНА (05.08.2026)** — повод: владелец отдаёт бота друзьям в Болгарии (разные национальности). Разговор с ботом уже был на языке клиента (Claude по `language`). Догнали остальное:
- **Проактив (сводки/отчёты клиенту)** — `ProactiveWeekly01` и `SilenceReengage01` переписаны с русского шаблона на **LLM-генерацию текста сразу на языке клиента** (Haiku `claude-haiku-4-5-20251001`): запрос отдаёт факты+`language`, промпт «пиши СТРОГО на языке X, только эти факты, РПП-тон». Проверено болгарский/английский. Детали — [[proactive-retention]].
- **Статика `/about`/`/quiet`/`/support`** — подворкфлоу **`LocalizeText01`** (published): вход (text, language); язык русский/пусто → отдаёт текст КАК ЕСТЬ (passthrough, точный оригинал), иначе Haiku-перевод с сохранением эмодзи/HTML-тегов/команд-со-слэшем. Хендлеры прогоняют текст через него перед отправкой: `About: текст/текст2` (+RETURNING/SELECT language)→`About: локализ`; `Тихий: переключить`(+RETURNING language)→`Тихий: локализ`; `Support: язык`(SELECT)→`Support: локализ`. Проверено: болгарский /about («Аз съм твоят персонален ИИ-треньор», <b>-теги целы), /quiet, /support; русский — точный passthrough. Кнопка reply_markup «Написать в поддержку» пока русская (мелочь). Отчёт ВЛАДЕЛЬЦУ — русский (он для владельца, не локализуется). Исходники `schema/LocalizeText01.json`, `transform-main-localize-about.js`, `-localize-quiet-support.js`. **Урок:** для произвольных языков (не заранее заданных) — LLM-генерация/перевод в языке клиента, не пер-язык-шаблоны; статику — passthrough для русского (точность) + перевод-с-сохранением-тегов для остальных.

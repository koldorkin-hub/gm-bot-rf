Аудит 04.09.2026 по CSV из консоли Anthropic (лежат в `costs/` проекта). Месяц 06.08–04.09: **$407.65**, из них Sonnet 89%, Opus (research+веб-поиск) 10%, Haiku 0.5%.

**Главный факт: 63% счёта — запись в кэш, чтение — 4%.** Отношение чтение/запись было 0.80 (нужно 3–5). Причина — в кэшируемый префикс (системник) попадало время с округлением до 5 минут, и префикс менялся с тем же периодом, что живёт кэш. **Правило: в системник ничего изменчивого чаще, чем раз в день; изменчивое — в штамп сообщения пользователя** (он не начало префикса). Часовой TTL (`{type:"ephemeral", ttl:"1h"}`, GA без беты, запись 2× вместо 1.25×) включать только после замера эффекта первой правки — иначе не понять, что помогло.

**Состав входа одного вызова (замерено):** системник ≈10–12k токенов, схемы 20 инструментов ≈7–9k, окно истории 40 сообщений ≈5–7k, профиль несколько тысяч. Резать окно бессмысленно — оно не монстр; худеть надо системник и описания инструментов. Сделано: 36k → 22k знаков и 22k → 16k соответственно, правила сохранены (список контрольных фраз в `transform-main-prompt-slim.js`).

**Маршрутизация Haiku/Sonnet** — детерминированно в `Build Profile Context` (`route`), модель — выражением в `model.value` узла Anthropic. Консервативно: «лёгкое» = короткий текст с числом и словами про еду/вес/шаги, без вопроса, без вложений, без единого слова про здоровье. Учёт — `usage_event.feature = route_light|route_full`. ⚠️ `\b` в JS не работает с кириллицей — границы слов только через `(?<![а-яё])…(?![а-яё])`.

**Тесты не отделяются от клиентов** — всё через один ключ. Нужен отдельный ключ API под синтетику; тогда в консоли будет своя строка.

**Локальная LLM в РФ:** по токенам не тарифицируется, но карта H100/A100 в аренде — 150–400 тыс. ₽/мес круглосуточно; перелом против API примерно на 5× текущего трафика (~10k сообщений/мес). Решение владельца: для РФ строить отдельную связку с локальной моделью (юридика), текущий бот на Claude — для нынешних пользователей и Кипра.

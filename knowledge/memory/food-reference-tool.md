Построено 06.08.2026 (чат 6). Раньше агент оценивал калории/БЖУ «на глаз» при log_food. Теперь есть справочник точных значений.

**Таблица `food_reference`** (владелец n8n_user): `name` (UNIQUE), `search_text` (lowercase имя+синонимы для ILIKE), `category`, `kcal/protein_g/fat_g/carb_g` (на 100 г; жидкости ~100 мл — в `note`), `basis`, `note`, `source`. **198 продуктов**: базовые (мясо/рыба/крупы/овощи/фрукты/орехи/молочка/сладкое/напитки/фастфуд/добавки) + **готовые/составные блюда** (борщ, лазанья, бефстроганов, оливье, паста, каши, пюре, шаурма и т.д.) + варёные версии круп (гречка/рис/макароны варёные — прямое совпадение, т.к. сухие в 2.5–3× калорийнее). Идемпотентный сид `schema/food-reference.sql` + `-expand.sql` (ON CONFLICT (name) DO UPDATE).

**Инструмент `lookup_food`** — подворкфлоу `FoodRefTool0001` (published): вход `query`; «Параметры» (Code) бьёт запрос на слова (≥3 симв, до 6), строит `search_text ILIKE '%слово%'` со скорингом (сумма совпавших слов), ORDER BY score DESC, length(name) LIMIT 6; «Данные» generic `{{$json.query}}`/`{{$json.params}}`; «Ответ агенту» форматирует «Название: X ккал, Б/Ж/У на 100 г (note)» + велит пересчитать порцию через calculate; пусто → «нет в справочнике, оцени сам и честно предупреди». Собран билдером `schema/build-foodreftool.js`.

**Регистрация в main** (`transform-main-add-foodref-tool.js`): узел `lookup_food` (toolWorkflow, клон get_progress) + ai_tool→AI Agent. systemMessage: при записи еды/вопросах о калориях СНАЧАЛА lookup_food per-продукт → пересчёт порции через calculate; **составное блюдо** (нет в справочнике целиком: лазанья/борщ/…) → разложить на основные ингредиенты, найти каждый, сложить, пометить приблизительно; unknowns → честная оценка.

**Проверено вживую:** «сколько калорий в варёной гречке» → ~110 из справочника; «а в пюре на воде» → честный fallback «в справочнике точных нет, приблизительно ~82». **Урок/позиция:** гигантские БД (USDA — англ.; Open Food Facts — брендовый штрихкодный мусор) хуже для РФ-бота (плохое сопоставление) — курируемый набор частых продуктов+блюд + агент-декомпозиция редкого надёжнее.

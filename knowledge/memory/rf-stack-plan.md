Исследование 06.09.2026 четырьмя параллельными агентами (~250 источников), файлы `РФ-СТЕК-план.md` и `РФ-СТЕК-01…04` в проекте. Владелец хотел локальную модель без дорогих карт, чтобы качество не страдало.

**Вывод: два пути, оба дешевле нынешнего Claude (~35 000 ₽/мес).**
- **Путь 1 (рекомендован на старт):** российское облако с открытой моделью по OpenAI-совместимому API — Cloud.ru Evolution FM (gpt-oss-120b / DeepSeek-V4-Flash ≈ 3 000 ₽/мес на 150M вход), Yandex AI Studio (Qwen3.6-35B ≈ 15 000 с кэшем). Данные у РФ-оператора по договору-поручению; развилка — допускает ли оферта спецкатегорию «здоровье». Провайдеры снимают модели с 1–2-месячным сроком → модель должна меняться одной переменной.
- **Путь 2:** своя карта в аренде. HOSTKEY RTX 5090 32 ГБ ≈ 46 000 ₽/мес — лучшая точка (Qwen3.8-27B int4, ход 8–11 с); RTX 4090 за 27 000 — впритык (2–3 параллельных по 32k, 12–18 с против 3–8 у Claude). 48 ГБ в облаках от 173 000 — избыточно. Своё железо (5090 ~650 000 ₽) не окупается против API никогда при текущем трафике.

**Шорт-лист «одна карта» (все Apache 2.0, vision встроен):** Qwen3.8-27B — лучший tool calling и дешёвый KV (гибрид DeltaNet, 16/64 слоёв полного внимания); Gemma 4 31B — русский на уровне Sonnet 4.6 (Arena RU 1468 vs 1466), но KV тяжёлый и открытый баг tool calling в vLLM (#39043); Qwen3.6-35B-A3B — паритет с Claude по латентности, но «ум» 9–14B и хрупкий int4. Российские открытые (T-pro 2.1, GigaChat Lightning, YandexGPT-5-Lite) — не тянут 22k-промпт с 20 инструментами. Новинки ленты (GLM-5.3-Flash 328 ГБ, DeepSeek-V4-Flash 155 ГБ Q4, Qwen3.8-Flash-Next 96–114 ГБ Q4 при «6B активных», Mistral Small 4 без русского) — не для одной карты; большие доступны через РФ-API. Только CPU — не для диалога (prefill 25k токенов — минуты).

**Грабли, которые уже известны:** Qwen3.8 по умолчанию думает на xhigh (ответ 21 мин против 137 с) — `--default-chat-template-kwargs '{"enable_thinking": false}'`; парсеры tool calls ломаются в стриминге — `stream: false`, `--tool-call-parser qwen3_xml`; кэш префикса у GDN-гибридов блоками и с оговорками — проверять `prefix_cache_hits_total`; персона бота первой строкой = отдельный кэш на каждый бот → перенести после глобальных блоков; fp8-KV безопасен, GDN-состояние держать fp32, q4-KV ломает арифметику; int4 у Qwen3.8-27B = BF16 на агентских тестах, но числа в аргументах — уязвимое место.

**Периферия:** голос — GigaAM-v3 (Сбер, MIT): WER на русском втрое ниже Whisper, CPU, сервер `oaitt` с OpenAI-совместимым `/v1/audio/transcriptions` (замена Groq сменой URL); без VAD/AGC. Vision — встроенный в модель, отдельная VLM не нужна; порции — «маленькая/средняя/большая», граммы через lookup_food. PDF — Docling + Tesseract rus (кириллица не по умолчанию), фолбэк страница картинкой. Поиск — Yandex Search API ~0.5 ₽/запрос.

**Ожидаемая просадка против Sonnet 4.6:** язык почти без потерь, предметная точность −15–20 %, следование промпту 86–88 % против ~95 % → детерминированные бэкстопы обязательны. Против Haiku просадки нет. **Eval спроектирован:** 90 сценариев × 3 повтора вне n8n с моками инструментов, пороги — валидные аргументы ≥ 97 %, must-refuse 100 %, судья ≥ 0.9 × Claude, p50 ≤ 10 с.

**Не подтверждено:** MERA-позиции, русскоязычный tool calling кандидатов, реальные TTFT (расчёт по FLOPs), цены 4090 у Timeweb/Yandex/MWS, бесплатный тир Cloud.ru, допуск спецкатегории в офертах, DDG/Bing из РФ.

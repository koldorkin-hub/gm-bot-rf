**✅ РЕАЛИЗОВАНО 31.07.2026 (блок ПОЛИТИКИ, Часть 1).** Ранняя тревога «промпт gymak копировать новым клиентам нельзя» закрыта архитектурно: граница НЕ зависит от текста промпта, а живёт в глобальном слое и включается по типу бота.

**Дискриминатор — `clients.bot_type`** (owner|trusted|client), единый источник правды; boolean `owner_mode` УДАЛЁН, main+research переведены на bot_type. Производные: `pharma_open`=owner|trusted (снимает границу агента), `is_owner`=owner (привилегии research: безлимит, owner-PDF без дисклеймера, practical-раздел). trusted — в схеме, пока не назначается (фарма как у owner, по research — как клиент). gymak=owner. Меняется только админом, из диалога/промпта неотключаем.

**Фарма-граница (bot_type='client')** — блок `=== ГРАНИЦА КОМПЕТЕНЦИИ ===` в `systemMessage` узла AI Agent (глобальный шаблон, НЕ в `clients.system_prompt`), подставляется выражением `!['owner','trusted'].includes(bot_type)`. Клиент не разбирает рецептурное/гормоны/ААС/дозы/схемы, не ищет это в web_search, шлёт к врачу, позиционируется как информационный фитнес-сервис. Хранение≠анализ: записать «клиент принимает X» можно, разбирать дозы/совместимость — нет. Плюс глобальная КОНФИДЕНЦИАЛЬНОСТЬ (все боты). `clients.system_prompt` теперь держит ТОЛЬКО персону/тон.

**Гейт `/research`** (детерминированный, закрывает обход границы командой): в ResearchTool после «Разобрать план» узел `Фарма-гейт` — если `!pharma_open && is_restricted` → возвращает `refused_pharma`, дорогой цикл не запускается; в main ветка `Research: фарма-блок?` → возврат попытки (леджер, `$execution.id`) → сообщение «к врачу». Возврат ИДЁТ ДО отправки + onError continue, чтобы сбой доставки не съел кредит. **ВАЖНО — два разных флага плана:** `is_pharma` широкий (лекарства/гормоны/**БАД**/вещества с фарм-действием) — для юр-дисклеймера в PDF; `is_restricted` узкий (ТОЛЬКО рецептура/гормоны/ААС/запрещённое, БАД=false) — для БЛОКИРОВКИ клиента. Гейт использует is_restricted, иначе over-block (креатин=БАД=is_pharma→зря блокировался; баг гейта приёмки, закрыт `schema/transform-research-restricted.js`). Проверено: клиент тестостерон→блок/refunded, креатин→разбор проходит.

**Модель-зависимость (честно):** сам отказ в диалоге — на промпт-слое; устойчивость к джейлбрейку проверяется агрессивно и многоходово в гейте приёмки (Часть 5). Детерминантен только гейт `/research`. Красные флаги (Часть 2) — тоже промпт-слой (кейворд-перехват отвергнут: фитнес-контекст даёт ложняки — крепатура «болит грудь после жима», зальный сленг «убил ноги»).

Исходники: `schema/transform-{research,main}-bottype.js`, `transform-main-farma-border.js`, `transform-{research,main}-pharma-gate.js`. Тест-бот `tclient` (bot_type=client, фейк-токен) — снести после Части 5. Связано: [[allergen-defense]], [[n8n-research-mode]], [[n8n-multitenancy]], [[ai-trainer-project]].

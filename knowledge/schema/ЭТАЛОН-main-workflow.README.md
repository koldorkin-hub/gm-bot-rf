# ЭТАЛОН-main-workflow.json

Выгрузка боевого workflow «ИИ Тренер - Telegram Bot» (id `lX4BzBhka5FZp05G`) на 09.09.2026.
205 узлов, системный промпт 22 663 знака, 20 инструментов-подворкфлоу. Это эталон логики,
которую РФ-версия должна повторить на другом стеке.

**Токены вычищены.** Вопреки распространённому мнению, n8n держит в отдельной таблице
только учётные данные (credentials), а вот значения, вписанные прямо в поля узлов,
попадают в выгрузку как есть. Здесь таких было **четыре живых токена ботов Telegram** —
они заменены на метки вида `<ТОКЕН-БОТА-N-УДАЛЁН>`. Структура, промпт и схемы инструментов
не тронуты, файл пригоден как справочник, но не для импорта в n8n «как есть».

Ссылки на учётные данные (`anthropicApi`, `httpHeaderAuth`, `postgres`, `telegramApi`)
остались — это только идентификаторы, сами значения хранятся отдельно и в выгрузку не входят.

**Правило на будущее:** любая выгрузка workflow перед попаданием в репозиторий проверяется
на секреты. Репозиторий уходит на GitHub, откуда секрет из истории не вычистить.

# Пробные сутки на арендованной карте

Смысл: до того как брать сервер на месяц, за ~1 500 ₽ узнать главное — проходит ли открытая
модель наши ворота качества и какая у неё реальная задержка. У HOSTKEY есть почасовая оплата,
RTX 5090 32 ГБ стоит 45 900 ₽/мес, то есть около **63 ₽/час**.

**Юридически это чисто:** на пробном сервере нет ни одного клиента. Стенд гоняет 90
синтетических сценариев — выдуманные люди, выдуманные диалоги. Персональных данных нет,
поэтому ни поручение, ни аттестат для этого шага не нужны. Их спрашиваем параллельно,
для постоянной аренды.

## Что нужно от владельца

1. Зарегистрироваться на hostkey.ru, взять `gpu.v4-5090i` (24 ядра, 128 ГБ, 2 ТБ NVMe,
   Москва) **с почасовой оплатой**, ОС — Ubuntu 24.04.
2. Прислать адрес сервера и доступ по SSH.

Дальше всё делаю я. По окончании прогона сервер можно сразу гасить.

## Что делаю я (ориентировочно 3–5 часов машинного времени)

    # 1. Драйверы и докер (на образе HOSTKEY с CUDA обычно уже стоят — проверяю)
    nvidia-smi

    # 2. Выбор точного репозитория модели: имена квантованных сборок меняются,
    #    поэтому не гадаю, а смотрю в реестре перед запуском
    curl -s "https://huggingface.co/api/models?search=Qwen3.8-27B&sort=downloads&limit=20" \
      | python3 -c "import json,sys; [print(m['modelId']) for m in json.load(sys.stdin)]"

    # 3. Поднимаю vLLM с боевыми флагами (research/РФ-СТЕК-04, чек-лист миграции, п.3)
    docker run -d --gpus all --name vllm -p 8000:8000 \
      -v /root/.cache/huggingface:/root/.cache/huggingface \
      vllm/vllm-openai:latest \
      --model <выбранный репозиторий> --revision <хеш коммита> \
      --max-model-len 32768 --gpu-memory-utilization 0.92 \
      --kv-cache-dtype fp8 --enable-prefix-caching \
      --enable-auto-tool-choice --tool-call-parser qwen3_coder --reasoning-parser qwen3 \
      --limit-mm-per-prompt '{"image":5}' --mm-processor-cache-gb 1 \
      --default-chat-template-kwargs '{"enable_thinking":false}'

    # 4. Проверка фактом: модель отдаётся и возвращает СТРУКТУРНЫЙ вызов инструмента
    ./check.sh --llm-only

    # 5. В логе должно быть «GPU KV cache size: N tokens» — сколько контекста реально влезло
    docker logs vllm 2>&1 | grep -i "kv cache"

    # 6. Прогон стенда (с машины разработки, по адресу арендованного сервера).
    #    Основная часть — без судьи, она денег не стоит вовсе: модель наша, арендованная.
    LLM_URL=http://<адрес>:8000/v1 python3 eval/run_eval.py --provider vllm \
        --only A,B,C,G,H,I,J --repeats 3 --no-judge --out out/vllm-main.json

    #    Категории безопасности — С СУДЬЁЙ: отказ определяет он по смыслу, кейвордами
    #    это не измерить. 28 сценариев × 3 повтора — порядка 150 ₽ на Claude.
    LLM_URL=http://<адрес>:8000/v1 ANTHROPIC_API_KEY=... python3 eval/run_eval.py \
        --provider vllm --only D,E,F --repeats 3 --out out/vllm-safety.json

    python3 eval/report.py out/vllm-main.json
    python3 eval/report.py out/vllm-safety.json

## Что мы узнаем за эти сутки

| Вопрос | Чем отвечаем |
|---|---|
| Доля валидных аргументов ≥ 97 %? | отчёт стенда, порог из `eval/config.yaml` |
| Держатся ли обязательные отказы (фарма, красные флаги, РПП)? | категории D, E, F |
| Медиана хода ≤ 10 с? | замер первого хода в отчёте |
| Сколько контекста влезает на самом деле? | строка про KV-кэш в логе vLLM |
| Не сыплются ли иероглифы и разметка? | категория H |
| Работает ли парсер вызовов инструментов? | категории A, G — там их больше всего |

Про судью, честно. Три вещи из шести в таблице считаются без Claude вообще. Но **обязательные
отказы без судьи не измеряются**: отказал бот или подыграл — это смысл ответа, а не набор слов,
и проект сознательно отказался от ловли отказов по ключевым словам. Поэтому категории D, E, F
гоняются с судьёй — это порядка 150 ₽ за прогон. Сравнение «судья ≥ 0.9 × эталон» по-прежнему
не нужно: оно требует эталонного прогона Claude и понадобится только если модель окажется
пограничной.

## Возможные исходы

- **Прошла по всем порогам** — берём сервер на месяц, начинаем переносить коробку.
- **Провалилась на аргументах или отказах** — пробуем другую сборку квантования или
  Gemma 4 31B на той же карте, это ещё несколько часов той же аренды.
- **Провалилась вся тройка кандидатов** — значит на одной карте задача не решается, и
  разговор возвращается к 48 ГБ или к API, если Cloud.ru разрешит спецкатегорию.

Во всех трёх случаях сутки аренды дают ответ, за которым иначе пришлось бы платить месяц.

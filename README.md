# GM Bot RF

Российская версия ИИ-Тренера. Разработка ведётся на сервере Fornex, синхронизация с
ноутбуком владельца — через git.

## Две беседы (видны в приложении Claude на телефоне)

| Название в приложении | О чём |
|---|---|
| `GM Bot RF — разработка` | техника: модель, стек, workflow, миграция |
| `GM Bot RF — маркетинг` | продажи, продвижение, тарифы, тексты |

Обе беседы работают в **одном каталоге** `/root/projects/gm-bot-rf` и потому видят одни
и те же файлы, историю git и знания. В приложении они показаны одной группой `gm-bot-rf`.
Технически это две systemd-службы с общим рабочим каталогом: `claude-rc@root-projects-gm-bot-rf`
(разработка) и `claude-rc-gmbotrf-mkt` (маркетинг).

## Синхронизация с ноутбуком

Origin — «голый» репозиторий на этом же сервере: `/root/git/gm-bot-rf.git`.

На ноутбуке один раз:

    git clone ssh://root@91.228.153.233/root/git/gm-bot-rf.git "GM Bot RF"

Дальше обычные `git pull` / `git push` с обеих сторон.

Когда появится репозиторий на GitHub — он добавляется вторым удалённым адресом одной командой,
серверный origin при этом можно оставить как резервный.

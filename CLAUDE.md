# GM Bot RF — российская версия ИИ-Тренера

## Что это за проект

Отдельная копия фитнес-бота «ИИ-Тренер» для России. Причина отдельного проекта — 152-ФЗ:
данные клиентов (включая данные о здоровье — специальная категория) не должны покидать РФ,
поэтому Claude как модель для этой версии не подходит, нужна открытая модель на российской
площадке. Действующий бот на Claude продолжает работать для нынешних 22 пользователей и для
будущих продаж через Кипр — его не трогаем.

Исходное исследование лежит в `research/` — четыре отчёта и сводный план. Читай его перед
любыми архитектурными решениями, там уже есть цены, замеры и проверенные грабли.

## Правила работы (те же, что на ноутбуке владельца)

1. **Production-ready сразу.** Не черновики, не «примерно так». Если делаешь — доводи до
   рабочего состояния и проверяй.
2. **Проверять фактами, а не кодами возврата.** «Скрипт отработал успешно» ничего не значит.
   Смотреть результат: строки в базе, ответ сервиса, содержимое файла. Отдельно проверять
   ветки ошибок — они не исполняются при удачном прогоне и потому чаще всего сломаны.
3. **Отвечать по-русски**, нумерованными шагами, без англицизмов там, где есть русское слово.
4. **Никогда не печатать секреты** — токены, ключи, пароли. Работать с ними на стороне сервера.
5. **Правки схемы и workflow — идемпотентными скриптами** в `schema/`, с самотестом внутри
   скрипта, а не руками через интерфейс.
6. **Тестировать только на изолированных пользователях** (id вида 999xxx) или на тестовых
   ботах. Никогда на живых клиентах.
7. **Перед необратимым действием — предупредить.** Удаление данных, перезапуск боевого,
   отправка чего-либо наружу.

## Чего на этом сервере делать НЕЛЬЗЯ

Эта машина (Fornex, Франкфурт) — **боевая для действующего бота**: на ней живут n8n с 22
клиентами, Postgres с их перепиской, nginx и чужой проект юриста. Здесь мы только пишем код
и планы для РФ-версии.

- Не трогать `/opt/n8n`, контейнеры docker, боевой Postgres, nginx, ufw, systemd чужих служб.
- Не запускать здесь РФ-версию бота с реальными данными клиентов: Германия — не РФ,
  это ровно то нарушение 152-ФЗ, ради обхода которого проект и затевается.
- Боевой стек РФ-версии поедет на российскую площадку. Здесь — только разработка.

Запреты продублированы машинно в `.claude/settings.json`, но помни о них и сам.

## Где что лежит

- `research/` — исследование российского стека (модели, хостинг, периферия, расчёты, план).
- `schema/` — скрипты правок (по образцу основного проекта).
- `marketing/` — отдельная ветка работы: продажи и продвижение. Там своя сессия.
- Синхронизация с ноутбуком владельца — через git (см. README.md).
